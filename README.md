# War Games

## Objectives
- Create a flexable,easy-to-use, correspondence-based wargame that can be played with paper and pencil.
- Design unit cards that describe special combat units and add a immense variety to the game.
- Generate income by selling access to new and updated unit cards.

## Key Concepts
- Play entirely on paper
- Players place simultaneous orders
- Unit cards describe abilities and range of actions
- Same rules can be applied to different periods and environments
- Combat results obtained by combining multiplies
- Risk tables combine attacker and defender keys to generate random curve-adjusted muliplies
- Also create terrain cards that describe how differnt terrains affect movement and combat
