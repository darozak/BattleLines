# DV-01-A1: Docs to keep current

1. <a id="1"></a>When a change affects players or how the project works, update these docs in the same change. This list is the one in `CLAUDE.md`, "Docs to keep current"; keep the two the same.

   1. <a id="1.1"></a>`README.md`: what the game is, how a game works, the live site link, the developer setup and the code layout.

   2. <a id="1.2"></a>`design.md`: how the game is built and why, the link format, turn resolution and versioning.

   3. <a id="1.3"></a>`rules.md`: the rules of play, published as the Rules page of the live site, per [DV-02](../SOPs/DV-02%20Maintaining%20the%20rules.md).

   4. <a id="1.4"></a>`CLAUDE.md` and `CONTRIBUTING.md`: when the change alters how the project is run.

   5. <a id="1.5"></a>The SOPs in `Procedures/`, when the change alters a procedure, per [QA-01](../SOPs/QA-01%20Writing%20and%20maintaining%20Battle%20Lines%20standard%20operating%20procedures.md).
